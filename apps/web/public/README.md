# PDF Hidden Text Remover

PDF 안에서 사람에게는 보이지 않는 AI와 텍스트 추출기만 읽을 수 있는 문장을 찾아 제거합니다.

업로드한 PDF는 서버로 전송되지 않습니다. 분석과 파일 생성은 브라우저 안에서 처리됩니다.

## 감지하는 항목

- 배경과 글자색의 대비가 매우 낮은 텍스트
- 지나치게 작은 글자
- 투명도가 낮거나 표시되지 않는 렌더링 모드
- 페이지의 보이는 영역 밖에 배치된 텍스트

## 사용 방법

1. 위 영역에 검사할 PDF를 놓거나 **PDF 선택** 버튼을 누릅니다.
2. 감지된 문장과 감지 근거를 확인합니다. 만약 잘못된 문장이 제거될 수 있기에 검토를 진행한 후 제거할 항목만 선택해 제거할 수 있습니다.
3. 제거할 항목을 선택하고 정리된 PDF를 내려받습니다.
